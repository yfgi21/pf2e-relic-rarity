# Changelog

## 2.2.0

- Renamed the public project to **PF2e Relic Rarity** (`pf2e-relic-rarity`).
- Added migration support from the former `alpha-pf2e-rarity` namespace.
- Added public manifest/download metadata for Foundry package installation.
- Replaced bundled development audio with original synthesized module sounds suitable for redistribution.
- Preserved rarity customization, item presentation, loot beams, Aeon Stone armor sockets, and the v2.1.8 equipment-power calculation.
